# Employee Lifestyle & Salary Analysis

This project explores how employee lifestyle choices—such as healthy eating and active living—correlate with their salaries.

## 📊 Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Excel
- PowerPoint

## 📁 Dataset Columns
- `id`
- `group`
- `age`
- `healthy_eating`
- `active_lifestyle`
- `salary`

## 🔍 Key Insights
- Positive correlation between healthy habits and salary.
- Identified salary outliers (e.g., employee with healthy_eating > 8 and salary < 1000).
- Subsets created for further analysis (high healthy eating, low salary, both).

## 🎯 Goals
- Recommend HR initiatives based on health metrics.
- Improve wellness strategies using data-driven insights.
